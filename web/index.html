    开始对话

    双击 Windows 桌面的「语音 Buddy」。打开页面后可先点「样音测试」，再允许麦克风并开始录音。

    从 Mac 连接

    1. 让 Mac 和 Windows 连到同一局域网，保持 Windows 和语音服务运行。
    2. 首次使用时，从 Windows 页面下载局域网公用 CA 证书，传到 Mac，在「钥匙串访问」中信任其 SSL 证书。下载局域网公用证书
    3. 在 Mac 打开上方 HTTPS 地址，用用户名 voice 和 Windows 的 .voice-lan/access.json 中的 password 登录，然后允许浏览器使用麦克风。

    连不上时，确认 Windows 防火墙允许专用网络访问 HTTPS 端口（默认 8443），不要在路由器上转发端口。
